A circuit is a path

Electricity only flows when it has a complete circuit: a closed path from one end of the dry cell, through the bulbs and switch, and back to the other end. Open the switch and the path has a gap, so the bulbs go out.

Two ways to connect bulbs

In a series circuit the bulbs are in one line, so the electricity has only one path. In a parallel circuit the path splits into branches, and each bulb has its own branch.
